Embedding Google Sheets

The standard pattern we use to embed a "publish to web" Google Sheet as a live, always-current view — no export step, no stale screenshots, just an iframe pointed at the source of truth.

The Reusable Pattern

Any Google Sheet that's been published to the web can be dropped into a page as a live iframe. Once published, the embed always reflects the current state of the sheet — no manual re-export needed.

<iframe src="https://docs.google.com/spreadsheets/d/e/PUBLISHED_ID/pubhtml?widget=true&headers=false" width="100%" height="500" frameborder="0"> </iframe>

To get this URL: in Google Sheets, go to File > Share > Publish to web, choose the specific sheet tab (or range) you want to expose, and click Publish. Google gives you a URL ending in /pubhtml.

Appending ?widget=true&headers=false to that URL hides the sheet-tab bar and the row/column headers, so the embed reads like a clean table instead of a full spreadsheet app.

Adding a New Sheet Embed

  1. Publish the sheet. In Google Sheets, go to File > Share > Publish to web, select the specific sheet tab you want to expose, and click Publish.
  2. Add the embed flags. Copy the generated URL and append ?widget=true&headers=false to the query string (use & to add it if the URL already has a ?).
  3. Drop it into an iframe. Paste the finished URL as the src of an <iframe> using the pattern above.
  4. Add a card block. Follow the Controls/Forecasts/Reporting example pattern above — an eyebrow label, a title, a short description, and the embed — on this page or a new one.
  5. Mind what you publish. Publish-to-web sheets are viewable by anyone with the link. Do not publish sheets containing sensitive data.
